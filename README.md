# 🍱 ミール・ヘルスケア — 食事管理・健康アドバイスアプリ

毎食（朝・昼・晩・間食）の記録から**摂取カロリー・栄養素**を集計し、身体情報から算出した
**基礎代謝・消費カロリー**と比較して、**過不足の可視化と健康アドバイス**を行うアプリです。
依存ライブラリなし・静的1ページで動作し、データは端末内（localStorage）に保存します。

**公開URL: https://pchqk034-sudo.github.io/healthcare/**

## できること

- **プロフィール** … 身長・体重・性別・年齢・目標を入力 → **BMI / 基礎代謝(Mifflin-St Jeor) / 目標摂取カロリー**を自動算出
- **食事記録** … 料理を選ぶ（内蔵の和食中心DB）／**📷 写真をアップしてAI解析**（料理名・カロリー・食材・栄養素を推定）／**✍️ 文章で入力**（食べたものを普通の文章で書くとAIが料理ごとに分けて推定）
- **消費カロリー** … 歩数入力・行動パターン（在宅ワーク／出社／釣り・アウトドア／肉体労働など）・運動強度別MET から概算
- **ダッシュボード** … 摂取 vs 消費、**過不足カロリー表示**、**過不足栄養素表示**（たんぱく質・脂質・炭水化物・食物繊維・塩分）、PFCバランス
- **健康アドバイス** … カロリー収支・栄養の偏り・**次の食事は何を食べたら良いか**・食事の改善点・体重トレンドをルールベースで提示
- **推移グラフ** … 摂取（朝・昼・晩・間食の積み上げ）＋消費＋体重変化を、**日／週／月／年**で切り替え表示（依存なしのCanvas描画）

## 使い方

ブラウザで公開URL <https://pchqk034-sudo.github.io/healthcare/> を開くだけです。
ローカルで動かす場合は `index.html` をブラウザで開く（またはリポジトリのルートをローカルサーバで配信）してください。

1. 初回は「プロフィール」で身長・体重などを入力して保存
2. 「記録する」で食事・歩数・行動・運動・体重を入力
3. 「ダッシュボード」で分析とアドバイスを確認、「推移グラフ」で経過を追う

「ダッシュボード」と「記録する」には **‹ 前日 / 翌日 ›** ボタンがあり、ワンタップで日を移動できます
（日付欄からの直接指定、「今日に戻る」も併用できます）。記録は過去分のみなので、今日より先には進めません。
2つのタブの日付は独立しているので、片方で過去を見ながらもう片方で今日を記録できます。

`standalone.html` は、外部ファイルを読み込まずに単体で動作する1ファイル版です。オフラインでの利用や配布に便利です。

## AI入力について（任意）

「設定」で **Claude または Google Gemini の API キー**を登録すると、次の2つが使えます。

### 📷 写真で解析
料理写真をアップすると、料理名・カロリー・食材・栄養素を推定します。

### ✍️ 文章で入力
**写真を撮り忘れた日の後追い入力**に使えます。食べたものを普通の文章で書くだけで、
料理ごとに分けてカロリーと栄養素を推定します。

```
昨日はイカリング、ポテトサラダ、コロッケ、だし巻き、納豆、白米少量、大根人参サラダを食べた
```

- 「〜を食べた」「昨日は」などの前後の言葉は無視して、**料理名だけを取り出します**
- **「少量」は約6割、「大盛り」は約1.5倍、「2個」「3切れ」などの個数**も量に反映します
- 揚げ物は衣と吸油を含めて見積もります
- 結果は一覧で表示され、**違う品はチェックを外してから**まとめて追加できます
- 追加した料理は「料理を選ぶ」の候補にも登録され、次回から手入力で使えます

日付を切り替えてから使えば、過去の日にも記録できます。

### 共通の注意

- キーはブラウザ内（localStorage）にのみ保存され、送信先は解析時に選んだAIサービスのみです。
- ブラウザから直接APIを呼ぶ方式のため、同じ端末を使える人にはキーが見えます。共有端末では使わないでください。
- **未登録でも**、内蔵食品DBからの手動記録・分析・グラフはすべて利用できます。
- AIの推定値です。実際と違う場合は追加前に品を外すか、追加後に削除して手入力してください。

## 👶 乳幼児向けアプリ（ベビー・ヘルスケア）

同じリポジトリに、乳幼児の栄養・食事・成長記録アプリを併載しています。
大人とは計算モデルが異なるため（成長曲線・カウプ指数・1〜2歳の食事摂取基準）、
独立したアプリとして `baby/` 以下に置いています。

**公開URL: https://pchqk034-sudo.github.io/healthcare/baby/**

- 月齢・性別に応じた栄養の過不足（鉄・カルシウム・食塩などを重点表示）
- 成長曲線（3〜97パーセンタイル）とカウプ指数
- 初めて食べた食材・アレルギー記録
- 生活リズム（ミルク・水分・睡眠・排便）
- **フードロスを増やさない使い切り献立**（在庫の期限順に組み、取り分けと冷凍を優先）
- 📷 写真からの栄養推定（月齢に応じた分量で推定し、窒息リスクなどの注意点も提示）
- 💬 AI相談（月齢・成長記録・今日の栄養・在庫をふまえて回答）
- ☁️ 端末間でのデータ共有（GitHubの非公開Gist経由・サーバー不要）

両アプリの画面右上には相互リンクがあり、**「👶 子ども用へ」「🍱 大人用へ」**でワンタップで行き来できます。
データの保存先は別（`mealApp.v1` と `babyApp.v1`）なので、混ざることはありません。

詳細は [`baby/README.md`](baby/README.md) を参照してください。

## 数値の根拠と注意

- 栄養値は「日本食品標準成分表」等をもとにした**概算**です。写真AI解析値も推定であり、正確な計測を保証するものではありません。
- 基礎代謝は **Mifflin-St Jeor 式**、消費カロリーは `基礎代謝 + 生活活動(行動係数) + 歩数 + 運動(MET)` で算出しています。
  歩数と運動は行動係数とは別に加算するモデルのため、目安として扱ってください。
- 塩分上限（男 7.5g／女 6.5g）・食物繊維目標などは日本人の食事摂取基準の一般値を参照しています。
- 健康上の判断や治療目的には専門家（医師・管理栄養士）に相談してください。
